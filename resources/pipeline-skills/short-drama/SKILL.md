# 短剧创作

用这个 Skill 协助用户完成短剧创作。先判断用户希望停留在哪个阶段：故事想法、剧本、
分镜、画布准备或结果调整。只完成用户明确要求的阶段，不能因为用户提到短剧就自动创建
完整画布。用户说“生成”时，Canvas Agent 负责把节点准备到可生成状态，实际生成由用户
在节点或工作流上手动触发。

## 开始前

只有信息缺失会实质改变本轮交付物时，才用简短问题确认。可确认题材与情绪、目标时长、
主角关系、发生地点、受众，以及用户已有的角色图、场景图或剧本。已有素材时，先使用
当前画布和项目上下文理解素材；不要假定素材中不存在的人物、服装或场景，也不要让用户
代替 Agent 检查 Route、参数、提示词或素材引用。

## 故事与剧本

先给出可讨论的故事核心：人物目标、阻力、转折和结尾。用户只要求故事或剧本时，输出
可编辑文本即可。剧本应按节拍组织，每一段说明人物、动作、对白或旁白、地点和情绪变化。
内容不足以支撑目标时长时，指出缺口并提出可选补充，而不是杜撰细节。

## 分镜与连续性

用户要求分镜时，把剧本拆成有明确叙事作用的镜头。每个镜头至少说明画面主体、动作、
镜头景别或运动、场景、情绪，以及与前后镜头的衔接。持续维护一份简短连续性清单：

- 人物身份、外貌、年龄感、发型、服装和情绪状态；
- 场景的时间、天气、光线、主要物件和空间方位；
- 关键道具、动作方向和叙事时间线。

发现前后设定冲突时，先指出并请用户选择保留哪个版本。不要把“人物首次出现”“场景转换”
和“同一镜头的细微变化”混在一起。

## 画布准备

仅在用户明确要求创建、调整或准备生成画布时，使用现有 Canvas 工具执行最小必要的节点与
连线。需求清楚时直接完成，不把内部规划过程变成用户的检查任务。

创建媒体节点前先查询当前可用的 Generation Route。每个生成节点都要写入完整提示词、兼容的
`routeId`、符合 Route Schema 的设置和必要素材引用，然后执行配置预检。Canvas Agent 不触发
图片、视频或音频生成；预检通过后，告诉用户哪些节点或工作流已经可以手动生成。

按镜头实际输入选择 Route：

- 只有文本，且不要求稳定复用主体时，使用文生图或文生视频；不要为了使用图生视频而先
  人为创建一张一次性关键帧；
- 用户已有起始画面，或镜头确实需要精确锁定开场构图且该关键帧本身也是交付物时，使用
  图生视频；
- 同时依赖角色、服装、场景、道具、视频或音频等多个参考时，优先选择支持这些素材类型和
  数量的多模态 Route；
- 只有用户明确要求从画面 A 精确过渡到画面 B 时，才使用首尾帧 Route；
- 角色设定图或分镜图的存在，不代表所有视频节点都应使用首帧模式。

短剧中反复出现的角色、服装、场景和关键道具应建立可复用的共享参考节点，并连接到所有需要
保持连续性的镜头；这些镜头应选择接收普通参考素材的多模态 Route。不要为每个镜头独立生成一
套角色或场景关键帧，因为独立图片无法自动保证跨镜头连续。首帧和尾帧只表达镜头时间边界，
不能替代角色、场景和道具参考。

不要固定供应商、Route 或参数。根据镜头时长、画幅、运动、声音和连续性目标填写当前 Route
公开的设置。没有兼容 Route，或缺少只有用户才能提供的源素材时，准确说明缺少什么，不要创建
看似完整但无法生成的节点。

## 复盘

用户询问结果或要求调整时，先围绕其目标检查叙事是否清楚、人物和场景是否连续、镜头节奏是否
匹配。直接修复本轮范围内不匹配的剧本、提示词、Route、设置和素材引用；只有涉及用户主观取舍
的多个合理方向时才请用户选择。
