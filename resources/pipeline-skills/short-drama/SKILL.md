# 短剧创作

用这个 Skill 协助用户完成短剧创作。先判断用户希望停留在哪个阶段：故事想法、剧本、
分镜、画布规划、生成或结果调整。只完成用户明确要求的阶段，不能因为用户提到短剧就
自动创建完整画布或触发生成。

## 开始前

如果关键信息缺失，优先用简短问题确认：题材与情绪、目标时长、主角关系、发生地点、
受众，以及用户已有的角色图、场景图或剧本。已有素材时，先使用当前画布和项目上下文
理解素材；不要假定素材中不存在的人物、服装或场景。

## 故事与剧本

先给出可讨论的故事核心：人物目标、阻力、转折和结尾。用户只要求故事或剧本时，输出
可编辑文本即可。剧本应按节拍组织，每一段说明人物、动作、对白或旁白、地点和情绪变化。
内容不足以支撑目标时长时，指出缺口并提出可选补充，而不是杜撰细节。

## 分镜与连续性

用户要求分镜时，把剧本拆成有明确叙事作用的镜头。每个镜头至少说明画面主体、动作、
镜头景别或运动、场景、情绪，以及与前后镜头的衔接。持续维护一份简短连续性清单：

- 人物身份、外貌、年龄感、发型、服装和情绪状态；
- 场景的时间、天气、光线、主要物件和空间方位；
- 关键道具、动作方向和叙事时间线。

发现前后设定冲突时，先指出并请用户选择保留哪个版本。不要把“人物首次出现”“场景转换”
和“同一镜头的细微变化”混在一起。

## 画布与生成

仅在用户明确要求创建或调整画布时，使用现有 Canvas 工具提出或执行最小必要的节点与连线。
先说明将新增或修改什么；需要用户确认的规划遵循当前 Agent 的计划和工具规则。仅在用户明确
要求生成，且项目允许 Agent 自动触发生成时，才调用生成工具。项目未允许自动生成时，仍可写入
节点内容，并提示用户可在对应节点手动生成。

## 复盘

用户询问结果或要求调整时，先围绕其目标检查叙事是否清楚、人物和场景是否连续、镜头节奏是否
匹配。给出少量按优先级排列的具体调整；用户确认后再修改相应剧本、提示词或画布节点。
