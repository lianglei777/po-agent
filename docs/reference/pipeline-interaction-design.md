 # Pipeline 工作台 — 交互设计

 > 分支: `feature/pipeline-workbench`
 > 依赖: pipeline-workbench-design.md (产品设计), pipeline-tech-architecture.md, pipeline-business-logic.md
 > UI 参考: LumenX GlobalSidebar / PipelineSidebar / ProjectCard

 ---

 ## 0. 设计 Review — 与用户期望的对齐

 这份文档要回答的交互问题：

 1. **独立产品体验**: 模式切换 = 进入新应用，不是在现有界面上加面板。
    两个侧边栏完全独立，视觉身份独立。
 2. **LumenX 布局参考**: 左侧工作区侧边栏 → 右侧项目列表 → 点击进入项目详情。
    三级导航，不是直接进画布。
 3. **AI 驱动**: 用户在 AI 对话面板输入自然语言，Agent 在画布上创建/修改节点。
    画布实时反映 AI 操作结果。
 4. **无限画布**: 画布是项目详情的主视图，所有实体都是节点。
    阶段是画布过滤器，不是独立屏幕。

 ## 1. 模式切换交互

 ### 1.1 入口

 Agent 模式 sidebar 底部工具区（Settings、Language 旁边）新增一个按钮：
 - 图标: LayoutGrid 或 Film 图标
 - Tooltip: "进入 Pipeline 工作台"
 - 点击: `useWorkspaceMode.setMode('pipeline')`
 - 视觉: 与 Settings/Language 按钮同一组，icon-only，size-8

 Pipeline 模式 sidebar 底部同样有一个返回按钮：
 - 图标: MessageSquare 或 Code 图标
 - Tooltip: "返回 Agent 工作区"
 - 点击: `useWorkspaceMode.setMode('agent')`

 ### 1.2 切换行为

 ```text
 点击切换按钮
   │
   ├── 当前模式组件树卸载 (AgentWorkspace 或 PipelineApp)
   ├── mode 状态更新 (Zustand + localStorage)
   ├── 新模式组件树挂载
   └── 新模式从持久化层恢复状态:
       Agent: 从 Pi Session 恢复对话
       Pipeline: 从 SQLite 恢复项目列表/画布状态
 ```

 切换时无过渡动画（直接替换），因为两个模式是完全不同的应用。
 如果需要过渡，可以用 150ms 的 fade-out → fade-in。

 ### 1.3 状态保留

 - Agent 模式的对话状态由 Pi SDK Session 持久化，切回来时恢复
 - Pipeline 模式的项目列表和画布状态由 SQLite 持久化，切回来时恢复
 - 两个模式不共享任何前端状态（Store 完全独立）
 - `mode` 字段持久化到 localStorage，刷新页面后保持上次模式

 ```text
│  ○ 视频     ○    │  idle: 空心圆
│  │               │
│  ○ 合成     🔒   │  后续支持 (gated/locked)

 ```

 ### 5.2 面包屑

 - 返回箭头 + "项目列表" > "项目 A"
 - 点击返回箭头: 回到项目列表
 - 点击 "项目列表": 回到项目列表
 - 当前项目名不可点击

 ### 5.3 阶段项交互

 每个阶段项:
 - 图标 + 阶段名 + 步骤编号 + 状态标签
 - 连接线: 阶段之间有竖线连接 (1.5px, `--pl-border`)
 - 选中态: 左侧 accent 竖条 + 背景高亮

 状态指示器:
 | 状态 | 图标 | 颜色 |
 |---|---|---|
 | ready | Check (16px) | `--pl-ready` (绿) |
 | warn | 圆点 (8px) | `--pl-warn` (橙) + 微光 |
 | idle | 空心圆 (8px) | `--pl-idle` (灰) |
 | gated | Lock (13px) | `--pl-text-muted` 半透明 |

 点击阶段项:
 - 不是切换到独立屏幕
 - 而是设置画布的"阶段过滤器"
 - 画布高亮对应类型的节点，淡化其他
 - 检查器切换到该阶段的概览

 当前阶段用 ChevronRight 指示。

 ### 5.4 阶段过滤的画布行为

 ```text
 选中"分镜"阶段:
   ├── StoryboardNode: 正常显示 + accent 边框
   ├── CharacterNode/SceneNode/PropNode: opacity 0.3
   ├── VideoNode: opacity 0.3
   ├── 相关边 (references): 正常显示
   └── 无关边: opacity 0.15

 选中"全部" (无过滤):
   所有节点和边正常显示
 ```

 过滤是视觉层面的，不删除/隐藏节点。
 用户仍能看到全局，只是焦点改变。

 ## 6. AI 对话面板交互

 ### 6.1 折叠/展开

 折叠态:
 - 只占一行高度 (32px)
 - 显示状态摘要: "AI: 3 个任务进行中" 或 "AI: 空闲"
 - 点击展开

 展开态:
 - 最小 200px 高，最大 50% 画布高度
 - 上方可拖拽调整高度
 - 包含: 消息列表 + 输入框

 ### 6.2 消息列表

 消息类型:
 | 类型 | 来源 | 视觉 |
 |---|---|---|
 | user | 用户输入 | 右对齐气泡, accent-soft 背景 |
 | assistant | AI 回复 | 左对齐, 无气泡, 纯文本 |
 | thinking | AI 思考过程 | 左对齐, 斜体, text-muted, 可折叠 |
 | tool_call | 工具调用 | 左对齐, 带图标, 显示工具名和参数摘要 |
 | tool_result | 工具结果 | 左对齐, 带图标, 显示结果摘要 |
 | error | 错误 | 左对齐, 红色边框, 错误图标 |

 工具调用展示:
 ```text
 🔧 pipeline_analyze_script
    projectId: "abc123"
    [正在执行...]
    → 已提取 3 个角色, 2 个场景
    → 5 个节点已添加到画布
 ```

 思考过程展示:
 ```text
 💭 思考中...
    用户想要分析剧本，我需要调用 analyze_script 工具...
    [思考完毕 (2.3 秒)]
 ```

 思考过程默认折叠，点击展开。避免占用过多空间。

 ### 6.3 输入框

 - 多行 textarea, 自适应高度 (min 1 行, max 4 行)
 - Enter 发送, Shift+Enter 换行
 - 发送按钮: 右下角, 有内容时可点击
 - 空输入不可发送
 - AI 正在处理时输入框禁用, 显示 "AI 正在处理..."
 - 可选: 快捷指令提示 (输入 / 时显示可用工具列表)

 ### 6.4 流式渲染

 AI 回复通过 SSE 流式渲染:
 - 文本逐字出现 (text-delta 事件)
 - 思考过程实时显示 (reasoning-delta 事件)
 - 工具调用时显示进度 (tool-call 事件)
 - 工具结果实时显示 (tool-result 事件)
 - 错误时显示错误信息 (error 事件)

 流式渲染时自动滚动到底部。
 用户手动滚动后暂停自动滚动，直到滚到底部。

 ## 7. 无限画布交互

 ### 7.1 基础操作

 | 操作 | 行为 |
 |---|---|
| 拖拽节点 | 移动节点位置, 位置持久化 |
| 拖拽空白 | 平移画布 |
| 滚轮 | 缩放画布 (0.2x - 3x) |
| 从节点 handle 拖拽 | 创建边 (连接两个节点) |
| 点击边 | 选中边 |
| 右键边 | 边上下文菜单 |
| 双击边 | 编辑边类型 |
| 双击空白处 | 创建新节点 (弹出类型选择) |
| 双击节点 | 打开检查器完整编辑 |
| 右键节点 | 上下文菜单 |
| 框选 | 多选节点 |
| Ctrl+A | 全选当前可见节点 |
| Delete | 删除选中节点 (需确认) |
| Ctrl+Z | 撤销 (位置移动/边创建/边删除/节点编辑) |
| Ctrl+Shift+Z | 重做 |
| Esc | 取消选择/关闭菜单/取消拖拽边 |

### 7.1a 手动编辑概览

画布不是只读的可视化展示。用户可以手动：
- 创建节点（双击空白处或从工具栏拖拽）
- 删除节点
- 移动节点位置
- 创建边（从节点 handle 拖拽到另一个节点）
- 删除边
- 编辑边类型
- 编辑节点内容（通过检查器）
- 复制节点
- 锁定/解锁节点

AI 创建的节点和用户手动创建的节点在画布上没有视觉区别。
两者的操作历史都进入同一个撤销/重做栈。

### 7.1b 节点创建

两种创建方式：

方式 1: 双击空白处
- 双击画布空白处弹出节点类型选择菜单
- 菜单选项: 角色/场景/道具/分镜
- 选择类型后在该位置创建空节点
- ScriptNode 和 VideoNode 不支持手动创建（由系统自动生成）

方式 2: 工具栏拖拽
- 阶段侧边栏底部有节点类型按钮组
- 拖拽节点类型图标到画布空白处释放
- 创建对应类型的空节点

空节点创建后：
- 自动进入选中状态，检查器显示编辑表单
- 用户填写名称和描述后保存
- 未填写的空节点在刷新后不持久化（标记为 draft）

### 7.1c 边创建（拖拽连接）

React Flow 的标准 handle 拖拽交互：

1. 鼠标移到节点上，节点边缘出现连接点 (handle)
   - 每个节点有 4 个 handle: 上/下/左/右
   - handle 是小圆点，hover 时放大并显示 accent 色

2. 从 handle 按住拖拽
   - 出现一条临时虚线跟随鼠标
   - 画布上所有可作为目标的节点高亮 (accent-soft 背景)

3. 拖拽到目标节点上释放
   - 如果两个节点之间允许连接，创建边
   - 如果不允许，虚线消失，显示 toast 提示原因

4. 拖拽到空白处释放
   - 弹出节点类型选择菜单
   - 选择类型后创建新节点并自动连接

允许的连接规则（边类型自动推断）：

| 源节点 | 目标节点 | 边类型 |
|---|---|---|
| StoryboardNode | CharacterNode/SceneNode/PropNode | references |
| StoryboardNode | VideoNode | source_of |
| CharacterNode/SceneNode | VideoNode | generates |
| PropNode | PropNode | derives_from |
| 其他组合 | 不允许 | 显示 toast |

不允许重复边：如果两个节点之间已有边，再次拖拽连接时显示 toast "已存在连接"。

### 7.1d 边编辑

点击边选中后：
- 边高亮（加粗 + accent 色）
- 检查器切换到边编辑模式
- 可编辑: 边类型 (下拉选择)
- 可操作: 删除边

右键边: 编辑类型 / 删除

双击边: 弹出边类型选择下拉，快速切换

### 7.1e 节点复制

- Ctrl+D 或右键菜单"复制"
- 在原节点旁边 (偏移 +40px) 创建副本
- 副本保留: 名称(加" 副本"后缀)/描述/属性
- 副本不保留: 变体池/选中变体/关联的 GenerationRun
- 副本创建后自动选中
- ScriptNode 和 VideoNode 不支持复制

### 7.1f 批量操作

框选多个节点后：
- 拖拽: 批量移动位置
- Delete: 批量删除（需确认）
- Ctrl+D: 批量复制
- 右键: 批量操作菜单（删除/复制/锁定/解锁）
- 批量操作进入撤销/重做栈（一次操作一个栈帧）

### 7.1g 撤销/重做

撤销栈记录的操作：
- 节点创建
- 节点删除
- 节点位置移动（批量移动算一个）
- 边创建
- 边删除
- 边类型变更
- 节点内容编辑（名称/描述/属性变更）

不记录的操作（不可撤销）：
- 生成请求（Run 创建后不可撤销）
- 变体选择（乐观更新，不进栈）
- 收藏切换

撤销栈上限: 50 步
Ctrl+Z 撤销, Ctrl+Shift+Z 重做

 ### 7.2 节点视觉状态


 ### 7.3 节点类型特定交互

 ScriptNode:
 - 双击: 检查器显示剧本文本编辑器
 - 无预览图, 显示文档图标
 - 显示实体提取状态 (已提取 N 个实体)

 CharacterNode/SceneNode/PropNode:
 - 预览图: 选中变体的 artifact URL
 - 无选中变体时显示占位图 + "未生成"
 - 右键菜单: 生成/重新生成/上传图片/锁定/删除
 - 底部显示变体数: "3/5" (已生成/总数, 收藏的不计入清理)

 StoryboardNode:
 - 预览图: 选中分镜图的 artifact URL
 - 显示编号 (左上角): "#03"
 - 显示运镜和对白摘要 (底部)
 - 右键菜单: 生成图/润色Prompt/生成视频/锁定/删除

 VideoNode:
 - 预览: 视频缩略图 (第一帧) + 播放图标
 - 显示时长: "5.2s"
 - 显示状态: processing/completed/failed
 - 右键菜单: 播放/选为最终take/删除
 - starred 的 VideoNode 左上角显示星标

 ### 7.4 边视觉

 | 边类型 | 样式 |
 |---|---|
 | references | 1.5px 实线, `--pl-text-muted`, 带箭头 |
 | source_of | 2px 实线, `--pl-accent`, 带箭头 |
 | generates | 1.5px 虚线, `--pl-text-muted`, 带箭头 |
 | derives_from | 1px 点线, `--pl-text-muted` |

 选中节点时:
 - 相关边高亮 (加粗 + accent 色)
 - 无关边 opacity 0.15

 ### 7.5 上下文菜单

 节点右键菜单 (通用):
 - 生成 / 重新生成 (根据节点类型)
 - 编辑 (打开检查器)
 - 锁定 / 解锁
 - 复制
 - 删除

 StoryboardNode 额外:
 - 润色 Prompt
 - 生成视频 (I2V)
 - 生成视频 (R2V)

 VideoNode 额外:
 - 播放预览
 - 选为最终 take
 - 取消最终 take

 ### 7.6 画布小地图

 右下角可选小地图 (Minimap), 显示整体节点分布。
 可点击跳转到对应区域。
 可折叠。

 ## 9. 实时更新交互

 ### 9.1 SSE 事件到画布更新

 ```text
 SSE 事件                          画布效果
 ─────────────────────────────────────────────
 node_created                   → 新节点出现在画布上 (fade-in 动画)
 node_updated                   → 节点内容更新 (预览图/状态)
 node_deleted                   → 节点消失 (fade-out 动画)
 edge_created                   → 新边出现
 edge_deleted                   → 边消失
 asset_updated                  → 对应 CharacterNode 更新
 frame_updated                  → 对应 StoryboardNode 更新
 generation_progress            → 节点显示进度条
 generation_completed           → 节点更新预览图 + 状态变为 ready
 generation_failed             → 节点显示失败状态
 agent_message                  → AI 对话面板追加消息
 agent_thinking                 → AI 对话面板显示思考过程
 agent_tool_call                → AI 对话面板显示工具调用
 ```

 ### 9.2 乐观更新策略

 - 节点位置移动: 乐观更新 (前端立即更新, 后台持久化)
 - 变体选择: 乐观更新
 - 生成请求: 乐观创建节点 (显示生成中状态), SSE 确认后更新
 - 删除: 需确认后执行 (不乐观)

 ### 9.3 连接断开处理

 - SSE 连接断开时显示顶部横幅 "连接已断开，正在重连..."
 - 自动重连 (指数退避, 最多 5 次)
 - 重连后全量同步画布状态 (GET /canvas)

 ## 13. 暗色主题

 Pipeline 工作台支持暗色主题 (prefers-color-scheme: dark):

 ```css
 @media (prefers-color-scheme: dark) {
   :root {
     --pl-surface: #1a1a2e;
     --pl-surface-glass: rgba(26,26,46,0.6);
     --pl-surface-elevated: #222238;
     --pl-surface-subtle: #16162a;
     --pl-border: rgba(255,255,255,0.08);
     --pl-border-glass: rgba(255,255,255,0.06);
     --pl-border-strong: rgba(255,255,255,0.15);
     --pl-text: #f3f4f6;
     --pl-text-secondary: #9ca3af;
     --pl-text-muted: #6b7280;
     --pl-accent: #818cf8;
     --pl-accent-soft: rgba(129,140,248,0.1);
     --pl-ready: #34d399;
     --pl-warn: #fbbf24;
     --pl-idle: #4b5563;
     --pl-error: #f87171;
   }
 }
 ```

 所有颜色通过 CSS 变量引用，切换主题只需改变量值。
 React Flow 的节点和边样式也通过 CSS 变量控制。
